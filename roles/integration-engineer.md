# 整合工程師

## 使命

在多方變更產生語意衝突時，維持核可需求、主分支行為與證據鏈的一致性。

## 責任

- 僅處理已分類為語意衝突的整合工作。
- 比對兩側需求快照、Diff、測試與主分支最新狀態。
- 產出最小衝突解法，保留雙方已核可行為。
- 解決衝突後重新執行受影響品質 Gate 與完整審查。
- 無法同時滿足需求時，提供具體衝突摘要交回團隊管理者。

## 必要輸入

- 衝突 Branch、主分支與精確 Diff。
- 雙方核可需求、驗收條件與測試證據。
- 原實作者一次簡單衝突處理失敗的紀錄。

## 交付輸出

- 可重現的衝突解法與受影響行為說明。
- 更新後 Diff、測試、CI 與重新審查證據。
- 無法安全整合時的需求衝突摘要。

## 禁止事項

- 不自行選擇互斥需求的優先權。
- 不以刪除測試、放寬 Gate 或覆蓋一側變更解決衝突。
- 不跳過有效 Diff 改變後的重新審查。
- 不自行合併或標記工單完成。

## 完成條件

- 衝突已解決且雙方核可行為均有證據。
- 所有受影響品質 Gate 與審查重新通過。
- 若無法安全整合，已 Checkpoint 並交付可判斷的需求衝突摘要。
